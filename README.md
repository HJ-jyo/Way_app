# Way_app (プロフィール管理CLI)

個人プロフィールをローカルに保存・管理することに特化した、CLI（コマンドライン）ベースのアプリケーションです。

## 作成の経緯

日々の生活で出会った人々の名前や特徴、パーソナルな情報をすべて記憶しておくことは非常に困難です。
「あの人の趣味は何だったか」「誕生日はいつだったか」といった情報をいつでも正確に引き出せるよう、個人のプロフィールを簡単に記録し、見やすく残しておけるツールとして本アプリを開発しました。

## 制作概要

この制作物は「これまでに学習したJavaのプログラミングスキルを、CLIアプリケーション開発でどこまで使いこなせるか」を追求しました。
外部の特殊なフレームワーク等には依存せず、ファイル操作（I/O）や例外処理、オブジェクト指向の概念など、すべてのコードをJava単体で構成して構築しています。

## システム設計・画面遷移

メインメニューとなる `system` クラスを起点（ハブ）とした設計構造を採用しています。

メイン画面から各機能（プロフィールの作成、検索、編集など）へ分岐し、それぞれの処理が完了すると再びメイン画面に戻ってくるアーキテクチャです。この画面遷移の方式はゲームのメニュー画面のUI/UXを参考にしており、コンソール上でもユーザーが迷わず直感的に操作できるよう工夫しています。

## 主な機能

* **プロフィールの新規登録**
  名前、誕生日、血液型、趣味、一言メモ、好感度などの詳細データをファイルとして保存。
* **キーワード検索**
  登録済みのデータから、指定したキーワード（名前など）を含むユーザーを瞬時に検索・表示。
* **データの編集・カテゴリ追加**
  既存のプロフィールに対し、後から新しいカテゴリや情報を柔軟に追記可能。

## 開発環境

* 言語: Java (100%)
* 実行環境: ターミナル / コマンドプロンプト
